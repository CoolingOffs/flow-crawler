# 快速入门指南 🚀

## 5 分钟快速上手

### 第一步：创建你的第一个文件夹

1. 点击左侧的 **"新建"** 按钮
2. 输入文件夹名称，例如："我的第一个爬虫"
3. 点击确认

💡 **提示：** 文件夹用于组织相关的流程步骤，每个文件夹对应一个独立画布页。

### 第二步：选中文件夹

1. 点击刚才创建的文件夹
2. 右侧会显示该文件夹的画布（目前是空的）
3. 左侧会出现**节点面板（NodePalette）**

### 第三步：拖入第一个节点

1. 在左侧节点面板的 **🌐 导航** 分类中找到 **"打开网址"**
2. **拖拽**到画布上
3. 画布上会出现一个节点，左上角显示序号 **#1**
4. 点击节点，右侧出现**配置面板**
5. 在 URL 输入框中输入网址，例如：`https://www.baidu.com`

### 第四步：添加第二个节点并连线

1. 从节点面板拖入 **"点击元素"** 节点到画布
2. 该节点自动编号为 **#2**
3. 从 **#1** 节点底部的 **输出端口** 向下拖拽，连接到 **#2** 节点的 **输入端口**
4. 点击 **#2** 节点，在配置面板中设置：
   - 选择器类型：选择 `ID`
   - 选择器值：输入 `su`（百度搜索按钮的 ID）

### 第五步：查看 JSON 预览

1. 右下角自动显示当前流程的 **JSON 配置**
2. 点击 **"复制 JSON"** 按钮可复制
3. 点击 **"执行 JSON"** 可直接在浏览器中运行

### 第六步：创建子文件夹（可选）

1. 点击文件夹右侧的 **➕** 图标
2. 输入子文件夹名称
3. 可以在子文件夹中创建更细分的流程

## 图编辑器操作指南

### 创建节点
- 从左侧 **NodePalette** 拖拽到画布
- 节点按拖入顺序自动编号（#1, #2, #3...）
- 序号在创建时即固定，不受连线影响

### 连线
- 从节点**底部输出端口**拖出
- 连接到下一个节点**顶部输入端口**
- 每个节点只能一入一出
- **双击连线**可删除连线

### 配置节点
- 点击节点打开右侧配置面板
- 配置参数、添加备注、设置打印日志
- 可临时禁用节点（执行时跳过）

### 删除节点
- 选中节点后按 **Delete** 键
- 删除后其余节点自动按位置重编号

### 定时任务（进阶）
- 拖入 **📅 定时任务** 节点
- 从定时任务节点的**顶部输出端口**向上回连到循环起始节点
- 配置 Cron 表达式或指定时间
- 配置面板会显示循环范围信息

## 功能演示示例

### 示例 1：百度搜索流程

```
节点 #1：打开网址
  URL：https://www.baidu.com

节点 #2：点击元素
  选择器类型：ID
  选择器值：kw（搜索框）

节点 #3：点击元素
  选择器类型：ID
  选择器值：su（搜索按钮）
```

### 示例 2：定时监控流程

```
节点 #1：打开网址
  URL：https://www.example.com/status

节点 #2：获取文本
  选择器类型：CSS 选择器
  选择器值：.status-text
  保存变量：statusText

节点 #3：定时任务
  类型：cron
  表达式：*/5 * * * *（每 5 分钟）
  ↑ 回连到节点 #1
```

## 常用技巧

### 1. 文件夹嵌套
- 使用子文件夹可以更好地组织复杂项目
- 例如：`爬虫项目 > 登录流程 > 登录步骤`

### 2. 变量使用
- 在"获取文本"等步骤中设置"保存为变量"
- 后续步骤使用 `${变量名}` 引用
- 左下角"变量管理"面板查看所有变量

### 3. 数据持久化
- 所有数据自动保存在浏览器本地
- 关闭浏览器再打开，数据依然存在
- ⚠️ **注意：** 清除浏览器数据会丢失所有流程

## 快捷键

- `Enter` - 确认新建/编辑文件夹
- `Esc` - 取消操作
- `Delete` - 删除选中节点

## 最佳实践

1. **命名规范**
   - 使用有意义的文件夹名称
   - 例如：`淘宝商品爬虫` 而不是 `test1`

2. **节点组织**
   - 按逻辑顺序从上到下排列节点
   - 使用连线建立执行顺序
   - 每个文件夹专注于一个功能

3. **备份**
   - 定期导出 JSON 配置
   - 使用"导出文件"保存本地备份
   - 避免意外丢失数据

## 常见问题

### Q: 我的数据保存在哪里？
A: 保存在浏览器的 LocalStorage 中，与浏览器绑定。

### Q: 为什么刷新后数据还在？
A: 这是正常的，数据自动保存和恢复。

### Q: 如何清除所有数据？
A: 打开浏览器开发者工具（F12）-> Application -> Local Storage -> 删除 `crawler_folders` 和 `crawler_canvasData`

### Q: 支持哪些浏览器？
A: Chrome、Firefox、Edge 等现代浏览器。

### Q: 节点序号可以手动调整吗？
A: 序号在创建时自动固定。如需调整，可以删除节点后重新拖入。

### Q: 定时任务的循环范围怎么设置？
A: 从定时任务节点的顶部输出端口向上回连到循环起始节点即可。
